# 鴨媽媽回家

一款手機直式的剪紙風網頁小遊戲。選擇當鴨媽媽或鴨爸爸，帶著 15 隻戴著不同小配件的小鴨，在 2 分鐘內沿著河游回農舍吃晚餐。

**線上試玩：** https://mochachen1225-create.github.io/ducks/

不用下載、不用註冊，手機瀏覽器打開就能玩。

## 玩法

- **按住拖曳**：家長跟著手指游，小鴨排成一列跟在後面。
- **放開手指**：大家停下來喘口氣，走散的小鴨會游回身邊；但水流會把隊伍往回推，老鷹也比較容易盯上不動的鴨群。
- **救回小鴨**：掉隊、被纏住或跑去吃麵包的小鴨，游過去碰牠一下就會重新跟上。
- **點小鴨**：會呱呱叫。
- **限時 2 分鐘**：時間到還沒到家就結束。

### 沿路危險（每局隨機出現，前段較少、後段較密）

石頭、老鷹、急流、浮木、漩渦、大鯉魚、小船掀浪、岸上小孩丟麵包、漂流垃圾（塑膠袋、釣魚線、寶特瓶、鐵罐）、撒網的漁夫。

中段有一個**河道分岔**：一邊是超級急流，另一邊水很平靜但石頭很多。最後一關固定是**瀑布**，水流會把隊伍往瀑布拉，左岸還有土堆擋路。家長自己游過頭也會掉下去。

### 結局

- **平安到家**：依帶回的數量給稱號，每一級都有幾句隨機台詞。
- **掉下瀑布**：THE END。
- **時間到**：趕不回去吃晚餐。

結算後可以分享成績圖或文字（支援 Web Share；不支援時改為下載或複製）。最佳紀錄存在瀏覽器裡。

## 素材來源

- **圖像**：全部是程式裡的內聯 SVG 和 Canvas 繪製，自行設計，沒有使用任何外部圖片。網頁預覽圖 `og.png` 也是用遊戲本身的素材產生的。
- **聲音與音樂**：全部用 Web Audio API 即時合成，沒有任何音訊檔。
- **字型**：「jf open 粉圓」（Google Fonts 上的名稱是 Huninn），採用 SIL Open Font License；載入失敗時改用裝置內建字型。
- 遊戲不連接任何 AI 或後端伺服器。

## 技術

- 單一 `index.html`，沒有建置步驟，直接用瀏覽器打開就能跑。
- 由 GitHub Pages 從 `gh-pages` 分支發佈。
- `tools/bot.js`：用 Playwright 自動試玩，粗略檢查難度。
